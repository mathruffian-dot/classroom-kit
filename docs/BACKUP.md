# 分享、備份與還原

## 三種輸出

- 課程 JSON：分享教材，包含課程、活動、正解及教師備註；不包含學生作答。給學生的未揭露內容由 API 過濾，請勿直接公開含答案的教材檔。
- 場次 JSON／CSV：教師下載個別作答紀錄，含座號等可辨識欄位，只存於受保護位置。
- 教師課堂備份 JSON：教材、班級、場次、作答與白板，排除教師密碼、SESSION_SECRET、學生識別碼及登入狀態。

**附件 BLOB 不包含在 JSON 備份中。** 請從「學生作答附件」逐件下載；需要整個資料庫的維護備份時，使用 Cloudflare D1 官方備份／匯出功能並保護該檔案，其中可能含敏感學生資料。

## 還原

教師匯入受信任的備份，後端先驗證身分、結構、數量與容量，再合併。已存在的資料不盲目覆蓋；錯誤不能部分提交。新還原班級重新產生班級代碼，個人識別碼不隨備份帶入。識別碼開啟時，由教師重發後學生才能加入；關閉時可直接以新班級代碼與座號加入。

一般請求上限 1 MiB，還原請求上限 9 MiB，還原後課堂資料總量仍須符合 8 MiB 上限；附件另計。不要把備份放進公開 repo 或公開教材下載區。

刪除場次會刪除該場次作答與附件；先下載要保留的資料。匯入課程不等於還原作答，不能互相替代。
