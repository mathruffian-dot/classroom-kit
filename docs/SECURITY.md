# 隱私與安全

正式部署使用自己的 D1 與 Worker Secrets。教師密碼至少 12 字元，SESSION_SECRET 為至少 32 字元的強亂數；只在後端使用，不放 Git、前端、教材、日誌或聊天。正式模式缺少設定時拒絕執行，不退回示範登入。

## 學生加入與資料範圍

預設不生成個人識別碼，知道班級代碼的人可選任何有效座號。這是方便的形成性活動模式，不能宣稱可驗證真實學生身分或防止冒用。需要較可靠的辨識時由部署者開啟 STUDENT_CODES_ENABLED。開啟後後端只存 HMAC 驗證值，明文只在產生／重發時提供；重發撤銷該座號舊登入。開關改變也使舊學生登入失效。

每份部署共用一個教師管理密碼，教師可管理這份部署的課堂。不要把它當作獨立教師帳號或跨校多租戶系統。教師、學生以獨立瀏覽器工作階段測試；前端隱藏按鈕不構成授權。

## 後端保護

- 相同來源檢查、HttpOnly 與 SameSite cookie，HTTPS 加 Secure；來源不符的寫入拒絕。
- D1 參數化 SQL、版本交易、提交唯一索引、輸入大小限制與每 IP 每 10 分鐘 200 次登入限制。
- 學生只能取自己班級的場次及自己座號答案；標準答案、解析與教師備註依揭露規則過濾。
- 檔案僅允許指定格式並檢查內容特徵、檔案大小與總量；下載前重新檢查場次與擁有者，以 attachment 與 nosniff 回傳，不把學生檔案公開成靜態網址。
- 匿名彙總不等於真正匿名問卷；教師仍能對照座號。

## AI 與 HTML

AI 必須由教師主動啟動；敏感題排除，僅傳允許分析的教材／去識別回答。未設定 AI 時顯示 mock。輸出供教師覆核，不自動改答案、成績或對學生貼標籤。每日次數限制不等於供應商費用保證。

自訂 HTML 在 sandbox 中透過受控 bridge 提交，不能持有金鑰、讀 cookie、直接連資料庫或載入外部追蹤。來源文字與學生輸入都視為資料，不是 Agent 指令。

## 公開與正式使用前

公開 repo 排除真實學生名冊、作答、個人識別碼、教師備份、Secret、cookie、瀏覽器狀態與含個資的截圖。只使用虛構測試資料與可散布素材。

自行設定保存期限，定期匯出並清理課堂與附件；附件不在課堂 JSON 備份中，刪除場次會一併刪除附件。正式使用前驗證跨班、跨座號、登出、重發、未揭露答案、並行提交、附件下載與故障重試。原始碼檢查與本機測試不代表雲端安全稽核或實機負載測試。
