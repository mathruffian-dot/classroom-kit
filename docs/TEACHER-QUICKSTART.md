# 老師一頁上手指南

1. 本機以 `npm run dev` 啟動虛構示範，按「教師示範」。正式網站輸入部署者自己的教師密碼。
2. 從課程工作台選課，或匯入符合教材格式的 JSON。各科都使用相同的教材與作答接口。
3. 建立班級與座號人數，複製學生入口或顯示 QR Code。學生個人識別碼預設不產生；部署者啟用時才下載並個別分發。
4. 開始上課、切換投影片、開放作答；學生以班級代碼與座號加入。啟用識別碼時再輸入個人碼。
5. 使用白板、抽籤與搶答，完成後公布統計。學生畫面不會提前收到教師備註及未揭露答案。
6. 開放題目後，學生可在「我的作答附件」上傳小型作答檔；教師從「學生作答附件」下載。單檔最多 1 MiB；請先縮小過大的照片。
7. 結束後匯出作答與課堂備份。附件不包含在 JSON 備份，刪除場次前另行下載。

預設每 10 秒同步；等待畫面更新即可，不需反覆重新整理。正式網址須為自己的 HTTPS 網址，開發電腦的 127.0.0.1 無法讓其他 iPad 直接連入。

識別碼關閉時不能防止冒用座號，不適合需要可靠驗證身分的考試。管理密碼不能交給學生。AI 非必要；顯示模擬分析時沒有呼叫外部供應商。
